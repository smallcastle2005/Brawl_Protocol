# 乱斗协议 · Brawl Protocol

一款俯视角像素竞技场战斗游戏，使用 **Phaser 3 + TypeScript + Vite** 开发，可直接在浏览器中运行。
设计重点放在**角色差异化机制**与**可计算、可调参的数值体系**上：七名角色各自拥有一套独立的资源/姿态系统，PVE 关卡则以「防御力乘区 + 技能预警」构建可读的战斗节奏。

> 当前版本为垂直切片 Demo：4 种玩法、7 名角色、2 个 PVE 关卡与 BOSS、装备成长系统。

---

## 玩法

| 模式 | 说明 |
| --- | --- |
| 乱斗 | 玩家 + 5 名人机，6 人混战，先达到击杀数获胜 |
| 团队推车 | 3V3 护送推车，推进到终点取胜 |
| 训练场 | 单人伤害测试，用于验证数值与连招 |
| 冒险模式（PVE） | 玩家 + 2 名 AI 队友逐波清怪，最终挑战关卡 BOSS |

每局地图随机，进入选人页后从七名角色中选择一名出战。

## 角色与核心机制

每名角色不是「技能组合」，而是一套独立运转的**协议**：

| 角色 | 定位 | 核心机制 |
| --- | --- | --- |
| 神枪手 | 远程爆发 | 命中叠层 → 高伤弹幕窗口 |
| 风之女皇 | 控场法师 | 脱手蓄力旋风、风场减速与自我加速 |
| 轰炸专家 | 范围毁灭 | 选点轰炸、引线叠层引爆、终极导弹锁定 |
| 奥术天选者 | 蓄力法师 | 登神蓄力（免控/减伤换输出）、能量球与奥术轰击 |
| 利剑舞者 | 近战刺客 | 招架蓄力减伤 → 格挡成功转化为剑势 → 消耗剑势的华尔兹穿刺 |
| 战争机器 | 火力压制 | 充能经济：过载充能 → 覆盖协议（激光/加特林双形态，左右键互斥） |
| 帝君 | 召唤指挥 | 雄兵召唤上限、三选一「方针」改变全局规则 |

## 数值与系统设计

- **统一伤害管线**：`基础伤害 × 来源增伤 × 暴击倍率 × 各类减伤 × 招架`，所有技能与子弹走同一条结算路径，便于集中调参。
- **防御力乘区**：`减伤 = 防御力 / (防御力 + 200)`。小怪 10、精英 30、心兽 80、西部双 BOSS 40；未来所有破防效果只作用于该防御力，不叠加新的减伤层。
- **受击半径分离**：`hitR` 与碰撞半径解耦，大体型 BOSS 的受击范围与视觉表现一致，避免「看起来打到了却没判定」。
- **预警优先于惩罚**：BOSS 大招先给出锁定射线/扩散圈/地面预警，再结算伤害，把难度放在「读招」而不是「猜招」。
- **资源互斥**：火力压制形态下左右键不能同时生效，用操作约束替代隐藏冷却，避免数值失衡。

详细设计见 [`乱斗协议-游戏策划案.md`](./乱斗协议-游戏策划案.md) 与 [`PVE说明文档.md`](./PVE说明文档.md)。

## 运行

```bash
npm install
npm run dev      # 本地开发
npm run build    # 类型检查 + 生产构建
npm run pack     # 打包成单个可双击运行的 HTML
```

`npm run pack` 会把产物内联为单个 HTML 文件，无需服务器即可离线游玩，便于分享试玩。

## 目录结构

```
src/
  scenes/      场景与流程（菜单 / 模式 / 选人 / 对局 / 图鉴 / 装备）
  sim/         战斗模拟：伤害结算、技能系统
    systems/skills/   各角色技能实现
  entities/    角色、子弹、导弹等实体
  modes/       玩法模式（乱斗 / 推车 / 训练 / PVE）
  pve/         关卡、怪物 AI 与 BOSS 技能
  render/      HUD 与表现层
  input/       输入采样与操作映射
  maps.ts      地图数据
  config.ts    全局配置与数值表
```

## 技术要点

- 表现与逻辑分离：模拟层不依赖渲染，便于单独调整数值与 AI。
- 数值集中在 `config.ts` 的 `BALANCE` 表，角色机制参数与战斗常数分离管理。
- 单文件打包：自研 `scripts/pack.mjs` 将 JS/CSS 内联，输出离线可玩 Demo。
